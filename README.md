# ai-author-support-00

This is an educational repository for authors to practice GitHub skills with AI vibecoding.

Purpose
- A lightweight starter repo for author-focused exercises using small, repeatable AI writing patterns.
- Helps authors practice Git workflows (edit, commit, branch, PR) while learning patterns they can reuse in writing.

How to use
1. Browse the short examples in `ai-isms/` for writing patterns (triplets and metaphors).
2. Try the prompt templates in `prompts/` to revise or brainstorm text with an assistant.
3. Copy a template, replace placeholders, and commit your own example to practice Git.

Structure
- README.md — this file: how to use the repo and suggested exercises.
- .gitignore — small cross-platform starter list.
- ai-isms/
  - triplets.md — three-line/three-part pattern examples.
  - metaphors.md — metaphor-creation pattern and examples.
- prompts/
  - revision-prompts.md — prompt templates for revisions.
  - brainstorming-prompts.md — brainstorming prompt patterns.

Suggested exercises (beginner-friendly)
- Exercise 1: Edit `ai-isms/triplets.md` to add one of your own triplets. Commit on a branch.
- Exercise 2: Use a prompt from `prompts/revision-prompts.md` to revise a short paragraph locally or with an editor extension.
- Exercise 3: Create a pull request with your edits and practice writing a helpful description.

Contributing notes
- Keep additions small and focused — one example per commit helps learning.
