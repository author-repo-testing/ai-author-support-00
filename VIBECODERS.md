# Notes for Assisting Agents

Use this repo like a workbook, not a lecture.

- Make small edits.
- Preserve the writer's voice over generic polish.
- Avoid flattening tone, genre, or character perspective.
- When revising, give a few useful options instead of a long list.
- Flag common AI patterns only when they feel generic or repetitive.
- Keep commit-sized changes focused and easy to review.
